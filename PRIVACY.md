# Privacy Policy

**Lumo Userscripts — Userscript Manager for Chrome**

## Overview

Lumo Userscripts is an open-source Chrome extension for managing and running userscripts. This privacy policy describes how it handles (or does not handle) user data.

## Data Collection

**Lumo Userscripts does not collect, store, transmit, or share any personal data or user information.**

Specifically, it does NOT:

- Collect browsing history, bookmarks, or download records
- Track user behavior or analytics
- Store personally identifiable information (PII)
- Transmit any data to servers owned or operated by the project maintainers
- Use cookies or any tracking technologies
- Access user data for advertising or marketing purposes

## User Scripts

All scripts, their source code, metadata and execution logs are stored locally on the user's device. Scripts run only on pages matched by rules the user configures. No script content is uploaded anywhere by the extension itself.

## Local Storage

Lumo Userscripts may store the following data **locally on the user's device** using the browser's built-in extension storage APIs:

- User preferences and settings (e.g., theme, language, UI scale)
- Installed userscripts and their metadata
- Script execution configuration and local logs

This data is stored entirely on the user's local device, is never transmitted to any server operated by the project maintainers, and can be deleted at any time through the extension's settings or by uninstalling the extension.

## Permissions

Lumo Userscripts requests browser permissions (such as `storage`, `scripting`, `activeTab` and side panel access) solely to provide its core functionality — installing, editing and running userscripts on pages the user chooses. These permissions are never used to collect or transmit user data.

## Third-Party Content

A userscript may itself contact third-party services. Such behavior is defined by the script's author and is outside the extension's control. Users should review scripts before installing them.

## Children's Privacy

Lumo Userscripts does not knowingly collect any information from children under 13 years of age.

## Changes to This Policy

If this privacy policy is updated, the changes will be reflected in this document. As an open-source project, all changes are publicly visible in the project's Git history.

## Contact

If you have any questions or concerns regarding this privacy policy, please open an issue on the project's GitHub repository.

---

*This privacy policy applies to the Lumo Userscripts browser extension distributed via the Chrome Web Store and/or built from source.*
